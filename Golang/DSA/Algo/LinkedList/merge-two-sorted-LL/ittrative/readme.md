Complexity Breakdown:

Time Complexity: $O(n + m)$ where $n$ and $m$ are the total number of nodes in `list1` and `list2` respectively. The algorithm traverses through each node of both lists at most once during the while loop, performing a constant amount of work at each step.

Space Complexity: $O(1)$ auxiliary space because it only rearranges pointers and allocates a constant number of new pointers/nodes regardless of the input sizes, requiring no extra memory proportional to the list lengths.
